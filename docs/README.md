# .hack reference

What is true about the four .hack PS2 games (CyberConnect2 / Bandai,
2002-2003) - Infection, Mutation, Outbreak and Quarantine - written for someone
who wants to write a parser or a subsystem. Generated by `tools/docs.py index` -
edit the pages, not this file.

The [worklog](../WORKLOG.md) is the other half: it says how each of these was
worked out. `status` below is the honesty knob - `solid` means every field is
accounted for, `partial` means named unknowns remain, `guess` means a hypothesis
nobody has knocked down yet. `volumes` says which games the page has been
checked against: `INF`, `MUT`, `OUT`, `QUA`, or `all`.
